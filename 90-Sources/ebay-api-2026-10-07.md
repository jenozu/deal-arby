# eBay API Integration Notes — 2026-10-07

## Decision
Use eBay's **Buy Browse API** `GET /buy/browse/v1/item_summary/search` as the initial live-listing discovery connector.

## Authentication
Browse API methods require an **Application access token**. Obtain it with OAuth client credentials at:

- Sandbox: `POST https://api.sandbox.ebay.com/identity/v1/oauth2/token`
- Production: `POST https://api.ebay.com/identity/v1/oauth2/token`

Credentials are the App ID / Client ID and Cert ID / Client Secret from the eBay Developer Program application keyset. The baseline scope is `https://api.ebay.com/oauth/api_scope`.

## Marketplace
Deal Arby defaults to `X-EBAY-C-MARKETPLACE-ID: EBAY_CA`, currency `CAD`, and country `CA`. Browse API supports the Canadian marketplace.

## Search
The connector uses keyword search, maximum source price, currency, and buying option filters. Initial operation remains fixed-price only. eBay's search filter syntax requires price to be paired with priceCurrency.

## Production-access caveat
Buy APIs can be used in sandbox, but production use is restricted and requires eBay approval/eligibility. A live production smoke test therefore depends on the user's eBay developer keyset having Browse API production access.
